# PPC Audit Lite (free)

The free census half of the **PPC Operator Toolkit**, a Claude skill that audits Amazon Sponsored Products search term reports and bulk files.

It counts and prices what needs no statistics: admissibility checks, coverage, duplicate serving (priced in dollars per year), and absence (never-served targets, isolation gaps, stranded queries). When a row needs a verdict, it says so and stops instead of guessing.

## Install

**Claude.ai:** turn on Settings → Capabilities → Code execution and file creation. Then Customize → Skills → + → Upload a skill → `ppc-audit-lite.zip`.

**Claude Code:**
```bash
mkdir -p ~/.claude/skills && unzip ppc-audit-lite.zip -d ~/.claude/skills/
```

## Use

Upload a Sponsored Products search term report (60 days, ending 7 days ago) or a bulk file and ask Claude to audit it. Nothing leaves your machine beyond your own Claude session.
